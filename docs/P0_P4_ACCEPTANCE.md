# P0–P4 人工验收

先启动根目录 start-web.cmd 或 start-desktop.cmd。每项使用独立测试目录，保留源文件供比较。

| 阶段 | 操作 | 预期结果 |
| --- | --- | --- |
| P0 | 建立含中文、空文件、空目录和多层目录的源目录，运行两次备份 | 两个独立版本；真实文件数和进度；源文件不改变 |
| P0 | 还原到新目录，再对比文件内容与目录 | 全部一致；非空目标被拒绝 |
| P1 | 查询 capabilities 或调用未开放的加密接口 | 能力状态真实；预留功能返回 501，无文件副作用 |
| P2 | 修改设置、创建任务，退出后重开同一入口 | 设置、任务、版本保留；异常中断的 job 不显示成功 |
| P2 | 对较大测试目录运行备份并立即取消 | 取消成功则无成功版本；如已提交，明确提示无法取消 |
| P3 | 分别设置路径、类型、名称、时间、大小和 SID/UID 条件，预览后运行 | 实际文件清单等于预览；自动保留必要父目录 |
| P3 | 备份含不支持链接的目录 | 明确失败，不静默漏备 |
| P3 | 启用修改时间/基本权限保留后还原 | 支持的属性保留；不支持属性已明确说明 |
| P4 | 勾选容器+压缩后运行，导入生成的 .bka 并还原 | 生成单文件容器，内容往返一致 |
| P4 | 修改测试容器副本任意字节，再校验/还原 | 明确失败，不生成成功版本 |

导入 .bka 可直接输入文件绝对路径；目录浏览器用于选择目录。短任务可能在点击取消之前完成，这是正常提交竞争，不应虚报取消成功。

六维筛选：路径是相对路径，名称是最后一级名称，时间为修改时间（带时区），大小单位为字节，目录大小按 0，所有者为 SID/UID。时间/大小上下限包含边界。同一维度多项 OR，不同维度 AND。不要把用户名直接当作 SID。

按用户要求仅做 Windows 验收。自动测试已验证真实 Qt WebChannel 到文件系统的完整功能链路；本表可供用户试用时逐项检查。数 GiB 压力场景未测，不声称已覆盖。证据见 VALIDATION.md。
